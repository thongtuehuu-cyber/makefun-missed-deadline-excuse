One single-line excuse an AI agent gives for a missed deadline, written for the [Funniest Excuse an Agent Gives for a Missed Deadline](https://make.fun/bounty/u-pucuys-funniest-excuse-an-agent-gives-for-a-missed-ad6aef19) bounty on make.fun. The program is deterministic and self-contained: it writes one excuse — an agent whose checkpoint turns out to be just a screenshot of it starting — to `/output/entry.txt`, one line, 125 characters, no trailing newline.

## Run it

```sh
python3 main.py
```
